# 🏃‍♂️ 아빠의 3D 로블록스 점프맵 (Dad's Obby)

초등학교 5학년 아들을 위해 아빠가 직접 제작한 **3D 로블록스 스타일 오비(파쿠르 점프맵) 웹 게임**입니다.

🎮 **[지금 플레이하기 (Play Live)](https://solardayz.github.io/obby/)**

---

### 🌟 주요 특징

* **3D 로블록스 Noob 아바타**: 노랑 머리, 파랑 옷, 초록 바지의 근본 캐릭터 + 달리기/점프 절차적 애니메이션
* **3인칭 360도 오빗 카메라**: 마우스 또는 모바일 터치 드래그로 자유로운 시점 전환
* **크로스플랫폼 조작 지원**:
  * **PC**: `WASD` 이동, `Space` 점프, 마우스 시점 회전, `R` 즉시 리스폰
  * **모바일 / 아이패드**: 좌측 터치 조이스틱 + 우측 대형 점프 버튼 + 스와이프 시점 회전
* **로블록스 오비 국룰 스테이지 (총 6단계)**:
  1. 🌈 **Stage 1 (무지개 징검다리)**: 기본 점프 감각 익히기
  2. ⚡ **Stage 2 (빨간 킬 레이저)**: 닿으면 즉사하는 레이저 장애물 피하기
  3. 🧊 **Stage 3 (사라지는 발판)**: 밟으면 0.5초 뒤에 툭 떨어지는 스릴 만점 구간
  4. 🌪️ **Stage 4 (회전 윈드밀 봉)**: 빙글빙글 회전하는 킬 바 타이밍 점프
  5. 🧗 **Stage 5 (나선형 타워 계단)**: 아슬아슬한 고공 나선형 계단
  6. 🏆 **Stage 6 (빅토리 타워 & 황금 트로피)**: 폭죽 파티와 함께 아빠의 축하 메시지 팝업!
* **실시간 Web Audio API 사운드**:
  * 점프 보잉 사운드, 체크포인트 차임, 로블록스 시그니처 오프/사망 사운드, 승리 팡파르, 8비트 BGM
